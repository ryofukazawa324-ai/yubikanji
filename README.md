# 指書き文字認識

スマホ・タブレット・PCのブラウザで、指・ペン・マウスを使って書いた日本語の手書き文字を認識する試作サイトです。

## 使い方

1. 四角いキャンバスに1文字を書く
2. 「認識する」を押す
3. 表示された候補をタップする
4. 選んだ文字が「入力結果」に追加される
5. 次の文字を書いて繰り返す

## 機能

- タッチ / ペン / マウス入力
- 1画戻す
- 全消去
- 日本語の認識候補を最大10件表示
- 候補をタップして文章へ追加
- 1文字削除 / 結果全消去 / コピー
- スマホ向けレスポンシブUI

## 手書き認識について

認識時に筆跡の座標情報を Google Input Tools の日本語手書き認識エンドポイントへ送信する試作構成です。このエンドポイントは公開された正式APIとして保証されているものではないため、Google側の仕様変更などで利用できなくなる可能性があります。

## GitHub Pages

`.github/workflows/pages.yml` を用意しています。初回のみリポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定すると、`main` 更新時に自動公開できます。
